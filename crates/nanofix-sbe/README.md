# nanofix-sbe

SBE (Simple Binary Encoding) codecs used by [`nanofix-aeron`](https://crates.io/crates/nanofix-aeron): the envelope that carries a FIX wire message over Aeron, and normalized order, cancel, replace, status and execution-report messages.

The code is generated by the official [`aeron-io/simple-binary-encoding`](https://github.com/aeron-io/simple-binary-encoding) Rust generator from [`schema/fix_aeron_envelope.xml`](schema/fix_aeron_envelope.xml). Regenerate it with `scripts/generate_sbe_bindings.sh` in the [nanofix repository](https://github.com/matthart1983/nanofix); don't edit `src/` by hand.

Most users want [`nanofix`](https://crates.io/crates/nanofix) or `nanofix-aeron` rather than this crate directly.
